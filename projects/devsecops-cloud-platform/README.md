# DevSecOps Cloud Platform

Security controls are integrated into delivery rather than bolted onto production.

## Controls

- Gitleaks for accidental secret detection.
- Trivy for container and filesystem vulnerability scanning.
- Checkov for Terraform/IaC policy checks.
- Dependency review for third-party risk.
- SBOM generation for artifact visibility.
- Least-privilege GitHub Actions permissions.
- Threat modeling before exposing a new trust boundary.

## Security rule

A scan result is actionable only when it has an owner, severity, remediation path, and an explicit exception process.
